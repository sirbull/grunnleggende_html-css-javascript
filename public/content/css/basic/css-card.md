## Hva lærer du?

Et kort er en liten samling innhold med en tydelig avgrensning. Bruk en klasse på beholderen og egne klasser der innholdet trenger særskilt stil. Da kan kortet gjenbrukes flere steder.
:::

:::step {"id":"mechanism","caption":"Se hvordan strukturen og resultatet hører sammen.","highlight":""}
## Slik henger det sammen

`border-radius` avrunder hjørnene. `box-shadow` kan gi en svak skygge. `max-width` begrenser bredden samtidig som kortet kan krympe på mobil. Unngå fast høyde når teksten kan vokse ved zoom eller oversettelse.
:::
