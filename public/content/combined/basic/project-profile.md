## Hva lærer du?

HTML beskriver navnet, beskrivelsen og knappen. CSS gir kortet luft og en kant. JavaScript lar brukeren vise et ekstra tips. Se hvordan hver del har et eget ansvar.

## Fra handling til resultat

Knappen endrer både hidden på teksten og aria-expanded på seg selv. Slik får både seende brukere og hjelpemidler informasjon om tilstanden. Bruk en ekte knapp for handlingen.
